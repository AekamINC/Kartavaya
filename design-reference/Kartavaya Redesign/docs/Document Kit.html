How the tenant layer works. Each organisation sets one attribute — data-org="saraswati" — and brand.css resolves its accent, tint, mark glyph and gradient from that. Documents reference var(--org-accent) and never a literal colour, so onboarding a new tenant is one block of six tokens plus its legal details. Switch tenant above, then open any document: the same file re-brands with no change to its markup.

Why these are print-owned. Statutory documents carry legal consequences if a field is clipped or a page breaks mid-table, so the fixed-layout ones pin their own page box and print at true size — letter or A4 — with no browser date/URL chrome. Long documents whose length varies, like a signed agreement, flow instead and let the print engine paginate.
