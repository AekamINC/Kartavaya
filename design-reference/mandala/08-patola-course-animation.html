पटोला भात — the course animation

Same motion as the six-geometries set: bands resolve outward from the centre, hold, and release together. The row-by-row shuttle is gone. It suits these motifs better than it suited the others, because Ratanchowk and Navratna are built concentrically — the animation now follows the drawing's own structure instead of cutting across it.

Six bhat

Cells are grouped into six radial bands. Runs are split at band boundaries so a rect never straddles two, which is what would make the courses tear as they scale.
