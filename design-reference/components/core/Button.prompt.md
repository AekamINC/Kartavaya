# Button

Kartavya's button component with three variants: primary (brand gradient), ghost (outlined), and reject (danger). Use primary for main CTAs, ghost for secondary actions, reject for destructive confirmations.

```jsx
<Button variant="primary">+ New task</Button>
<Button variant="ghost">Open project →</Button>
<Button variant="reject">Decline</Button>
<Button variant="primary" size="sm">Save</Button>
```

**Variants:** `primary` | `ghost` | `reject`
**Sizes:** `default` | `sm`
