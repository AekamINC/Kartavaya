# ProjectCard
Card for the Projects grid. Color bar, Sanskrit name, English name, client label, task/done/days stats, progress bar.

```jsx
<ProjectCard
  name="Quarterly GST filing"
  sanskrit="राजस्व"
  client="AEKAM INC"
  color="#0082c6"
  tasks={4} done={1} daysLeft={30}
  progress={0.62}
/>
```
