3 · When someone replies — two options

DO THIS NOW · COSTS NOTHING
Reply goes to their normal inbox
Customer replies→ invoice@abc.com→ their Gmail / Outlook

The accounts team keeps working where they already work. Nothing new to learn, nothing to build — the code already supports setting a reply address, it is simply never used.

LATER · THIS IS A BUILD
Reply appears inside Kartavaya
Customer replies→ Kartavaya→ on that invoice / contact

Whoever has Ganit access sees invoice replies; whoever has Graha access sees CRM replies. Permissions already work that way — nothing new there.

But this is a shared inbox: receiving, matching a reply to the right record, unread state, assignment. A week or more, and it keeps growing. Start with CRM only — that's the one place seeing it on the record beats seeing it in Gmail.

5 · The one thing that protects you

Keep marketing separate from invoices and payslips.

If one client's campaign draws spam complaints, it must not stop another client's payslip arriving. One setting per address does this — and it is the single most valuable change on this page.
