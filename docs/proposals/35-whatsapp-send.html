What it costs to send

Two ways to put that link in a WhatsApp chat, and they are very different purchases. Varta cannot send today — send_wa_message writes the row pending behind a TODO: Call Meta Cloud API, which is also why Prachar refuses WhatsApp campaigns.

Click-to-chatShips now, free. The button opens wa.me/91…?text=… with the message and link prefilled. Your staff taps send from their own WhatsApp. No Meta approval, no per-message fee, no template review. The limit is that it is manual and one client at a time — and that the send happens on their phone, so we only know it was opened, never that it was delivered.
Cloud API (Varta)Automated, and a real project. Sends without a human, gives delivery and read receipts, and can chase overdue invoices on a schedule. It needs the Meta Cloud API call finished, business verification, a pre-approved template for each message type, and a per-conversation fee. Invoice reminders are a utility template, the cheapest tier — but still a per-message cost that has to land on a pricing decision.

What the link earns you

  • The channel joins the scan log: ?src=wa alongside ?via=phonepe, so Collections can show WhatsApp against email against QR — sent, opened, paid.
  • An unopened link after five days is a real chasing signal. A PDF attachment tells you nothing at all.
  • The page always shows the current balance. A PDF sent in March still claims March's figure after a part payment in April; this cannot.
  • It refuses a settled invoice, so a forwarded chat cannot collect the money twice.

Decide these before it ships

  • The link is the credential. Anyone holding the chat can open it — forwarded, or on a shared family phone. It shows payee, invoice number, amount and the line items. That is exactly what a posted paper invoice exposes, but it is worth saying out loud rather than discovering later. If you want it tighter, the page can ask for the last four digits of the client's phone before revealing the lines.
  • WhatsApp shows a preview to whoever it is forwarded to — the thumbnail carries the client's name and the amount. If that is not acceptable, the preview can be reduced to the invoice number alone.
  • Click-to-chat sends from a personal number unless Cloud API is finished. Clients will reply to that number, not to the business.
