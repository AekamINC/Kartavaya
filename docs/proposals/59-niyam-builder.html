Run history — the real thing, not a counter

runrulesteps
The old builder showed a single run_count integer that rose whether or not anything happened. Here each run lists its steps and each step carries its own outcome — ok, refused, suppressed or dry — so a rule that is “working” and a rule that is quietly doing nothing look completely different.
