The honest trade: the shipped lotus does not read as a K. It reads as the product's own ornament, and it is the only one that is literally the same drawing as the loader and the message ground. A, B and C read as a K but introduce a second hand into the product — a new figure nothing else shares.

Favicon — at true 16px, then blown up

The left column is actual size in a browser tab. The right is the same drawing at 72px so you can see what is being lost.

A · one course + chip (shipped)
B · two courses + chip
C · no chip, accent ink
D · the eye only

My read: A. At 16 pixels a chip with one course still reads as a flower and keeps the accent visible, which is what makes it findable in a row of tabs. C loses the chip and thins out against a light tab strip. D is legible but is a circle — it could be anyone.
