The Same Five Minutes, Twice

Four things that happen in a normal working day, run through the automation that exists today and through Niyam. Same action, same rule, different answer. Every line on the left is a real behaviour found in the code on 16 August — file and line are in proposal 55.

The pattern underneath all four

Every failure on the left is the same shape: the product said yes and nothing happened. A rule shows Active and never fires. A log says success for an action that fell through every branch. A reminder is marked sent when it was suppressed. A screen offers auto-replies that nothing performs.

That shape is not a bug you can find by reading — it looks correct everywhere. It is only visible if the system is built so a claim has to point at evidence, which is why in Niyam a run step's proof of delivery is a foreign key into the outbound log rather than a boolean the engine sets about itself.
