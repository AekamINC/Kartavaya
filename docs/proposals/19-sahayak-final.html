What this settles. Focus collapses the rails to a centred column and nothing else changes. Workbench is the conversation rail only — no capability panel, as you asked; the RBAC filter still runs server-side, it is simply not narrated. Answer cards sit inside the bot reply, colour-coded by what each one is. Sources stay collapsed behind one button and open the split panel; clicking an inline [1] opens it with that card highlighted.

The lotus above is the real component — the same four courses, the same 3.2s trim, the same क in the eye. It is the avatar at rest and the thinking state while it works, so the waiting state and the brand are one thing rather than two. At 15.6s average latency it loops about five times.

One dependency worth naming: the three answer cards need the model to return structured sections rather than one block of prose. That is a backend change — a response schema plus a prompt that asks for it — not styling. If you want to ship sooner, the same layout renders a single card and upgrades later without touching anything else.
