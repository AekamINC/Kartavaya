The parity ledger

Element by element against the prototype stylesheets — tables, columns, rows, cards, layout, spacing — on web and on the phone. Every number below was resolved from source, not eyeballed. Where a value could not be resolved it is marked unverified rather than guessed.

The skeleton is right and the flesh is uneven. The shell, the token layer, the table primitive, the board, the task drawer and all nineteen mobile screens are built, and in many places they match the reference stylesheet to the decimal — the sidebar's .side* vocabulary matches app.css:27-72 declaration for declaration, and the mobile app has more screens than the prototype specifies. What is missing is concentrated and nameable: one whole control (the org switcher, which does not exist as designed anywhere in frontend/src), one whole screen (the DPDP attendance notice, which is a legal artefact and is absent), a set of columns that make Indian finance tables usable (place of supply, the taxable/GST split, the assignee), and one module that was never restyled — Graha still runs the pre-redesign vocabulary while Vikray and Ganit have moved. Of 104 serious findings raised across this handover, 5 did not survive re-checking against source; the other 99 stand.
