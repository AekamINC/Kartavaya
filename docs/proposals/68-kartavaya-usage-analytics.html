The pulse of Kartavaya

Aekam-only analytics about the product itself — who is using Kartavaya, how much, and where the energy is — never any tenant's business data. Lives in the Hub as a "Pulse" tab, visible to Aekam platform roles only. Every figure below is drawn with representative numbers; green tags mean the data already exists in the database today, amber means it needs a small new collector.

🔒Privacy shape (already decided): org-level aggregates and org names only — never a member's name, email, or personal row. Access is platform-role gated and writes an audit row. "From where" ships as state-level login geography with no raw IPs kept.

Ships as: a Pulse tab in the Hub, platform-role gated with an audit row per view; one read-only SQL module per card over existing tables (the same registry pattern the tenant analytics uses), so the first sixteen metrics need no schema change at all. The three amber ones each need one small, deliberately boring collector — say which you want and they get specced separately. Nothing here reads a tenant's business content: counts, names of orgs, and dates only.
