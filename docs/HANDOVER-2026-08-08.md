## Three things to know before touching this

**1. Gemini grounding does not work and switching models will not fix it.**
Probed live across every model the key can reach: plain `generateContent` → 200,
the same request with `google_search` → 429 on *all* of them. It is an
entitlement on the Google Cloud **project tier**, not a property of any model.
The £0.04 charge proves some project has it; the current key belongs to a
different one. Three earlier diagnoses were wrong (key format, billing absence,
retired model) — do not add a fourth without probing.

**2. The model catalogue lists models the account cannot use.** `models.list`
advertises 2.0 and 2.5; 2.0 is quota-zero (**429**) for keys issued now and 2.5
is closed to new users (**404**). Only 3.x answers. Never trust the catalogue or
the docs page — probe.

**3. Never a `-latest` alias.** That is what moved us onto 3.6 Flash and billed
without a code change. `GEMINI_TEXT_MODEL` / `GEMINI_GROUNDING_MODEL` in
`ai_router.py` are pinned, and `test_no_floating_aliases` fails on any alias.

## Web search

`backend/services/web_search.py`, keyed on `SERPER_API_KEY` (set on Railway
staging, verified live). Returns the exact shape `web_sources()` already
consumed from Gemini, so it drops into the existing socket with no UI change.

2,500 searches/month free, then $0.10/1,000 — against Gemini's $14–35. Searches
fire only when the planner missed *and* `looks_like_org_question()` is False,
roughly one question in four.

It earned its place immediately: ungrounded Gemini said GST on cement is 28%;
Serper found it was cut to 18% on 22 Sept 2025.

## Mobile

`build/Kartavaya-2.0.1-release.apk` — 66 MB, signed, built 14:09 from
`c5b1dead`. Contains the auth fix, the real Sahayak endpoint, the Android
keyboard fix, and ids removed from cards.

The logout bug was a race: `restoreToken()` reads SecureStore asynchronously and
`AuthProvider` fired `apiMe()` without waiting, so the request went out with no
Authorization header. Invisible in development because `__DEV__` sets the header
synchronously and Metro strips that branch from release. **Generalise this**: any
`__DEV__` shortcut that sets state synchronously may be masking an async race.

Test it with a **cold start** — `adb shell am force-stop com.aekaminc.Kartavaya`
— sign in, force-stop, reopen. Hot reload will not show the bug or the fix.

## Open, in the order I would take them

1. **Compare the £0.04 charge's project against the key's project** in the
   billing console. One lookup, and it either unblocks Gemini grounding or
   confirms Serper is the permanent answer. Needs the owner — I cannot see
   billing.
2. **The 7-day hard logout.** `/auth/refresh` exists (sliding 7-day) and mobile
   never calls it; the `res.data.token` branch in `apiMe` is dead because
   `GET /me` omits the token. Everyone is signed out on day 7. Wiring it is a
   behaviour change — rolling vs fixed sessions — so it needs a decision.
3. **Reorder the chatbot chain.** `_select_providers(task="chatbot")` leads with
   `gemini`, so every question spends prepay before reaching
   `thudm/glm-4.5-air:free`, which is literally free. One line, plus a test
   pinning free-before-paid. Biggest remaining saving.
4. **`auth_token` is not namespaced by `APP_ENV`** — a staging token and a
   production token collide on one device, which also reads as a logout.
5. **A per-org search/grounding counter.** Nothing counts either today, so
   crossing a free tier would be discovered from an invoice.
6. **`mobile/.easignore` is inert.** Added it; the archive stayed at exactly
   1.0 GB. EAS uploads take ~16 minutes and the free-tier queue is 3–4 hours,
   so this is worth solving before relying on cloud builds.
